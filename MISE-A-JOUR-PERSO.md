# Mettre à jour Android Hub (usage personnel, sans GitHub)

## Installer

Lancez **`releases\Android Hub-Setup-dernier.exe`**

## Mettre à jour après vos modifications

```powershell
cd "C:\Users\S_UN\Desktop\Android Hub - best"
npm run update:perso
```

Puis relancez **`releases\Android Hub-Setup-dernier.exe`** — l'installateur remplace l'ancienne version.

## Build sans incrémenter la version

```powershell
npm run build:perso
```
